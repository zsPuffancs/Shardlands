## Limits and unchanged balance

Low-level rounding and the existing early-game taper remain. Extreme underlevel kills are constrained by both the penalty and the recipient reference budget, independently for each eligible member. Summons pay no XP. Wisdom, server-rate and plugin caps are unchanged and covered by regression tests. Contract eligibility now uses the shared 25-level overlevel cutoff; the XP tables are unchanged. Boss/stone HP, DPS, respawn throughput, party mentoring speed and travel are not rebalanced here. Real XP/hour requires gameplay telemetry; no measured performance improvement is claimed. Existing saved-region levels/plans remain unchanged; their coverage is report-only in the Atlas.
